Vector Engine

Vector Graphics

Sprite Engine

Sprite & Blend Modes

Window.draw_image の新機能ショーケース。回転、拡大縮小・反転、ピボット位置指定、アルファ透過、ブレンド合成（通常・加算・乗算）を GPU Instancing で一括描画します。

  • 回転 (angle:)・拡大縮小/反転 (scale:)・ピボット指定 (pivot:)
  • 基準点配置モード (offset_mode: :top_left / :center)
  • :alpha, :add (加算発光), :multiply (乗算影) のブレンド合成

Texture Atlas

Texture Atlas & sub_image

1枚のテクスチャ (256x256) から切り出した sub_image 群を、自動バッチ結合により単一ドローコールで超高速描画。FBO への動的ベイクやリアルタイムテクスチャインスペクターを体験できます。

  • Image#sub_image (ゼロアロケーション部分参照)
  • Image.render_to (スロット領域への自動クリッピング描画)
  • 同一テクスチャIDによる自動バッチ結合 (1 ドローコール)
  • Window.draw_image の src_rect サンプリング

Clipping Engine

Hardware Clipping & Dual Coordinates

glScissor を用いたハードウェアクリッピング機能。画面全体の座標系を維持するグローバルマスクと、左上 (0, 0) を原点とするローカルビューポートの2系統座標系を体験できます。

  • Window.clip(local: false) - Ebitengine風親座標マスク
  • Window.clip(local: true) - UI/スクロール用ローカル相対座標系
  • 入れ子クリップ (Nested Clip) の交差判定自動算出
  • GPU レベルのピクセル単位ハードウェア切り抜き
